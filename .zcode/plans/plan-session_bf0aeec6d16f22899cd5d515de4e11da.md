# SpectraWall — процедурный генератор обоев (план реализации)

Генератор красивых градиентных обоев (в духе скриншотов: шёлковые цветные волны на тёмном/светлом фоне) с сидами, подробными настройками, экспортом от FHD до 16K и кастомного разрешения, историей генераций. Итерация 1 — статичные картинки; итерация 2 — зацикленная анимация и экспорт видео.

## 1. Стек и платформа
- **Веб-приложение**: TypeScript + Vite, рендер на **WebGL2** (фрагментные шейдеры), UI — vanilla TS без фреймворков (минимум зависимостей — хорошо для опенсорса).
- Запуск на Win/Ubuntu одинаково: `npm install && npm run dev`, продакшен — статика (`dist/`), можно хостить на GitHub Pages. Требования к ПК: любой браузер с WebGL2 (Chrome/Edge/Firefox/Safari ≥ 16).
- Зависимости runtime: **ноль**. DevDependencies: vite, typescript, vitest. Для итерации 2: `mp4-muxer` / `webm-muxer` (MIT, лёгкие).

## 3. Модель параметров и сиды
Единственный источник истины — один JSON (версионируется для обратной совместимости):
- `seed: string` — любой текст («wave-42»). Хэш сида → PRNG → все структурные параметры (число/позиции/изгибы волн, распределение цветов). **Одинаковый seed + одинаковые настройки = идентичный результат** в превью, в 16K и на любой ОС.
- `style: silk | mesh | aurora` — 3 стиля.
- `palette.colors: string[2..6]` — до 6 цветов, каждый можно **заблокировать** 🔒; кнопки: «Рандом палитры» (генератор гармоничных палитр в OKLCH — без грязных цветов), «Сменить сид».
- `background.theme: dark | light | custom`, `background.color` — чёрный фон (тёмная тема), белый (светлая) или кастомный цвет фона.
- `colorShare: 0..100%` — доля цветной области против фона (сколько «цвета» в кадре).
- `blur` (0..100), `grain.strength`, `grain.size`, `vignette` — пост-обработка.
- Advanced (сидируемые, с ручной поправкой): количество волн/пятен, интенсивность, масштаб структур.
- `animation.loopSeconds` — зарезервировано с итерации 1.

## 4. Рендеринг
- Все структуры в нормализованных координатах (aspect-corrected UV) → результат **не зависит от разрешения**, тайлы стыкуются бесшовно.
- Превью: реальный WebGL2-рендер в canvas (DPR-учёт), обновление на любое движение ползунка (<16 мс).
- Стили шейдерами: **silk** — доменно-искривлённые полосы шума через палитру (как на скринах); **mesh** — мягкие размытые пятна-блобы; **aurora** — туманные переливы. Внутри шейдера: зерно (абсолютный размер в пикселях — зерно в превью = зерну в 16K), виньетка, **дизеринг от бандинга** (критично для тёмных градиентов).
- Блюр: гауссов пасс (ping-pong FBO) поверх генерации.

## 5. Экспорт изображений (итерация 1)
- Пресеты: FHD 1920×1080, QHD 2560×1440, 4K 3840×2160, 5K 5120×2880, 8K 7680×4320, **16K 15360×8640**, ультраширокие 3440×1440 / 5120×2160, мобильные 1080×2340 / 1170×2532, **кастомные W×H** (до 16384×16384).
- Рендер тайлами ~4096px (юниформ-оффсет на тайл) → склейка → **PNG** (по умолчанию) или JPEG q95 (для 8K/16K быстрее/легче). Прогресс-бар + отмена; предупреждение о RAM на 8K/16K (~1–2 ГБ пик).
- Имя файла: `spectrawall-<seed>-3840x2160.png`.

## 6. История, пресеты, share
- **История** в IndexedDB: карточки с миниатюрой, датой, сидом; действия: открыть в редакторе, дублировать и изменить, переэкспортировать в другом разрешении, копировать сид, удалить. Ручное «Сохранить» + опция автосохранения. Экспорт/импорт коллекции JSON (перенос между ПК).
- **Share**: все параметры сериализуются в URL-hash (deflate + base64url) — «Скопировать ссылку» открывает генерацию у другого человека.
- Встроенные пресеты (Silk Noir, Neon Drift, Pastel Light, Aurora Deep, Sunset Haze…) + пользовательские пресеты.

## 7. Итерация 2 — анимация и видео
- Время — 4-е измерение шума, замкнутое по окружности → **идеальный бесшовный луп** без склеек.
- Живой анимированный предпросмотр (тумблер), выбор периода лупа.
- Экспорт: длительность 2–60 с, fps 24/30/60, разрешение (рекомендовано до 4K, 8K опционально), **MP4 (H.264, WebCodecs + mp4-muxer)**, фолбэк **WebM** (webm-muxer/MediaRecorder), плюс **ZIP с PNG-кадрами** для внешнего ffmpeg. Прогресс и отмена.

## 9. Проверка
- Vitest: детерминизм PRNG, roundtrip сериализации параметров/URL, генератор палитр (валидность hex, диапазоны OKLCH).
- Ручная матрица после реализации: экспорт FHD/4K/16K, одинаковость сида на разных разрешениях, тёмная/светлая/кастомная тема, импорт/экспорт истории. Визуальную проверку превью делаю скриншотами прямо в браузере в процессе работы.
