# SpectraWall

**Процедурный генератор обоев** — красивые шёлковые градиентные обои в любом разрешении, от Full HD до 16K, с кастомным размером. Бесплатно, опенсорс, работает в браузере на Windows, Linux и macOS.

## Возможности

- **Три генеративных стиля** — шёлковые волны, аврора, мягкий градиент; всё рендерится на GPU (WebGL2).
- **Любое разрешение**: FHD / QHD / 4K / 5K / 8K / **16K** (15360×8640), ультраширокие, телефонные или произвольные W×H до 16384×16384. Экспорт рендерится тайлами, поэтому огромные картинки работают на любом GPU.
- **Детерминированные сиды**: обои задаются строкой сида и параметрами. Тот же сид → та же картинка в любом разрешении и на любой ОС.
- **Подробные настройки**:
  - палитра: до 6 цветов, редактируемых и закрепляемых, либо гармоничная случайная палитра в один клик (цветовое пространство OKLCH);
  - тёмная / светлая тема или кастомный цвет фона;
  - доля цвета — насколько много кадра занимают цвета против фона;
  - мягкость, плёночное зерно (сила и размер), виньетка;
  - продвинутые (выводятся из сида, можно переопределить): слои, масштаб узора, искривление, блики, яркость.
- **История**: сохранённые генерации лежат локально (IndexedDB) с миниатюрами — открывайте, дублируйте, меняйте параметры, переэкспортируйте в другом разрешении. Импорт/экспорт всей коллекции в JSON.
- **Ссылки-шеры**: весь набор параметров сжимается в URL — отправьте ссылку, и у другого человека откроется ровно ваша картинка.
- **Пресеты**: 8 встроенных + свои сохранённые наборы настроек.
- **Интерфейс EN / RU**.
- Ноль runtime-зависимостей; продакшен-сборка ~19 КБ gzip. После первой загрузки работает офлайн.

## Быстрый старт

```bash
npm install
npm run dev        # дев-сервер → http://localhost:5173
```

Продакшен-сборка (статика, хостится где угодно — GitHub Pages, любой статический сервер):

```bash
npm run build      # результат в dist/
npm run preview    # локальный просмотр dist/
```

Требования: любой браузер с WebGL2 (Chrome, Edge, Firefox, Safari 16+). Для разработки Node.js 18+.
Экспорт 8K–16K лучше делать в десктопном браузере с парой гигабайт свободной ОЗУ.

## Как устроен рендер

Обои — один GLSL-фрагментный шейдер: сидированный шум с доменным искривлением, пропущенный через палитру, со стилевой структурой (анизотропные шёлковые листы, вертикальные аврора-занавесы или гауссовы цветовые пятна). Все координаты нормализованы по аспекту, поэтому композиция не зависит от разрешения; зерно считается в абсолютных пикселях, поэтому зерно в превью совпадает с зерном в 16K. Поверх добавляется дизеринг против бандинга на тёмных градиентах.

Экспорт рендерит сцену тайлами до 4096 px (с юниформом-смещением — бесшовно по построению) и стримит их через собственный PNG-энкодер на нативном `CompressionStream` — без лимитов canvas и без гигантских скачков памяти.
